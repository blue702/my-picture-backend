## 📖 项目介绍

基于 Spring Boot + Redis + COS + AI + WebSocket 的云图库平台，平台覆盖三大核心场景：

- **公共图库**：用户可上传、浏览、下载公开图片素材，适合设计资源、壁纸等共享场景。
- **个人私有空间**：用户拥有专属图片库，支持批量管理、智能检索、用量分析等功能。
- **团队协作空间**：用户可创建团队空间，邀请成员共同管理图片资产，并实现实时协同编辑、成员管理、用量分析等功能，大幅提升协作效率。

## ✨ 核心功能

| 模块       | 功能说明                                                     |
| :--------- | :----------------------------------------------------------- |
| 🔐 用户     | 注册、登录、信息修改                                         |
| 👤 个人空间 | 图片上传/删除、AI扩图、多维度搜索、扫码分享、存储统计        |
| 🌐 公共图库 | 图片上传/搜索、AI扩图、分类浏览                              |
| 👥 团队空间 | 成员邀请、角色权限（Sa-Token、RBAC）、图片共享、AI扩图、实时协同编辑 |
| 🛠️ 后台管理 | 用户管理、图片管理、图片审核、空间管理、空间数据统计看板     |
| ⚡ 高性能   | 多级缓存（Redis + Caffeine）、分页加载、缩略图、对象存储     |
| 🔔 实时协同 | WebSocket 实现协同编辑、Disruptor提升性能                    |

## 🛠️ 技术栈

| 层级         | 技术选型                                                     |
| :----------- | :----------------------------------------------------------- |
| **前端**     | Vue3 + TypeScript + Pinia + Vue Router + Ant Design Pro + Axios |
| **后端**     | Spring Boot 2.7 + MyBatis-Plus + Redis + COS + AI + WebSocket + Sa-Token + RBAC + Disruptor |
| **缓存**     | Redis + Caffeine                                             |
| **数据库**   | MySQL 5.7                                                    |
| **文件存储** | 腾讯云 COS                                                   |
| **实时通信** | WebSocket                                                    |
| **部署**     | 宝塔                                                         |
